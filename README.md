# 💱 Currency Converter CLI (Python)

A simple **Command Line Currency Converter** built with Python that converts one currency to another using real-time exchange rates.

---

# 📌 Features

* Convert between different currencies
* Uses real-time exchange rate API
* Simple command-line interface
* Beginner-friendly Python project

---

# 📂 Project Structure

```
currency_converter
│
├── currency_converter.py
├── requirements.txt
└── README.md
```

---

# ⚙ Requirements

* Python **3.x**
* `requests` library

Install dependency:

```bash
pip install requests
```

---

# 🚀 Run the Program

Navigate to the project folder:

```bash
cd currency_converter
```

Run the script:

```bash
python currency_converter.py
```

---

# 💻 Example

```
Enter base currency: USD
Enter target currency: INR
Enter amount: 50

Currency Conversion
50 USD = 4150.25 INR
```

---

# 🧠 Concepts Used

* API requests with `requests`
* JSON parsing
* User input handling
* Basic arithmetic operations
